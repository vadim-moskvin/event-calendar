# Event Calendar
Приложение для управления событиями.
## Особенности
- Поддержка CRUD операций для событий
- Валидация входных данных
- Реализация Swagger для документации API
## Сборка
dotnet build src/EventCalendar.sln
## Запуск
dotnet run src/EventCalendar.sln
## Тесты
dotnet test src/EventCalendar.sln
## Endpoints
### GET /events

Возвращает список событий. Поддерживает фильтрацию по названию и диапазону дат, а также пагинацию.

| Параметр   | Тип        | Обязательный | Описание                                                                             |
|------------|------------|-------------:|--------------------------------------------------------------------------------------|
| `title`    | `string`   |          Нет | Фильтр по названию события.                                                          |
| `from`     | `DateTime` |          Нет | Нижняя граница даты начала события.                                                  |
| `to`       | `DateTime` |          Нет | Верхняя граница даты окончания события.                                              |
| `page`     | `int`      |          Нет | Номер страницы. Если не указан, используется значение по умолчанию.                  |
| `pageSize` | `int`      |          Нет | Количество событий на странице. Если не указано, используется значение по умолчанию. |

### GET /events/{id}

Получить событие по id.
### POST /events

Создать событие
### PUT /events/{id}

Обновить событие целиком
### DELETE /events/{id}

Удалить событие
