# Event Calendar
Приложение для управления событиями.
## Особенности
- Поддержка CRUD операций для событий
- Валидация входных данных
- Реализация Swagger для документации API
- Добавление событий, созданных клиентом (указывая GUID идентификаторы)
## Сборка
dotnet build
## Запуск
dotnet run
## Endpoints
- GET /events — получить список всех событий
- GET /events/{id} — получить событие по id
- POST /events — создать событие
- PUT /events/{id} — обновить событие целиком
- DELETE /events/{id} — удалить событие
