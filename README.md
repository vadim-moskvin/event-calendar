# Event Calendar
Приложение для управления событиями.
## Особенности
- Поддержка CRUD операций для событий
- Валидация входных данных
- Реализация Swagger для документации API
## Сборка
dotnet build src/EventCalendar.sln
## Запуск
dotnet run src/EventCalendar.sln
## Тесты
dotnet test src/EventCalendar.sln
## Endpoints
### GET /events

Возвращает список событий. Поддерживает фильтрацию по названию и диапазону дат, а также пагинацию.

| Параметр   | Тип        | Обязательный | Описание                                                                             |
|------------|------------|-------------:|--------------------------------------------------------------------------------------|
| `title`    | `string`   |          Нет | Фильтр по названию события.                                                          |
| `from`     | `DateTime` |          Нет | Нижняя граница даты начала события.                                                  |
| `to`       | `DateTime` |          Нет | Верхняя граница даты окончания события.                                              |
| `page`     | `int`      |          Нет | Номер страницы. Если не указан, используется значение по умолчанию.                  |
| `pageSize` | `int`      |          Нет | Количество событий на странице. Если не указано, используется значение по умолчанию. |
| `pageSize` | `int`      |          Нет | Количество событий на странице. Если не указано, используется значение по умолчанию. |

### GET /events/{id}
Получить событие по id.

### POST /events
Создать событие

### PUT /events/{id}
Обновить событие целиком

### DELETE /events/{id}
Удалить событие

### POST /events/{id}/book
Забронировать событие. При остутствии свободных мест возвращает 409 Conflict.

### GET /bookings/{id}
Получить информацию о бронировании

## Событие
Содержит информацию о мероприятии: название, время и т.д.

### Модель
* Id - идентификатор события в системе
* Title - название события
* Description - описание события
* StartAt - дата и время начала события
* EndAt - дата и время окончания события
* TotalSeats - общее число мест
* AvailableSeats - число свободных мест

## Бронирование
Содержит информацию о резерации места на событие.

### Модель
* Id - идентификатор бронирования
* EventId - идентификатор события
* Status - состояние бронирования (ожидает, подтвержено, отклонено)
* CreatedAt - дата и время создания заявки на бронирование
* ProcessedAt - дата и время обработки заявки на бронирование

### Порядок работы с бронированием

1) POST /events/{id}/book - создаёт бронирование со статусом Pending, ожидающее подтверждения.
2) После обработки бронирование получает статус Confirmed в случае успеха или Rejected в случае отмены

Проверить статус бронирования можно с помощью GET /bookings/{id}. Ответ содержит:
1) Статус бронирования: Pending, Confirmed, Rejected.
2) Дату создания бронирования
3) Дату обработки бронирования (отсутствует в статусе Pending)
4) Идентификатор события
5) Идентификатор бронирования

### BookingService
Принимает запросы на бронирование и возвращает информацию об уже существующих заявках.

Использует SemaphoreSlim для объединения проверки события и резервации места в атомарную операцию, тем самым защищая 
сервис от овербукинга (число одновременных запросов превышает число свободных мест).

### BookingProcessor
Обрабатывает заявки на бронирование в фоновом режиме. 

Использует SemaphoreSlim для объединения проверки события и 
подтверждения бронирования в атомарную операцию.
